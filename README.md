# Multi-disease Prediction System

## Overview

The **Multi-disease Prediction System** leverages machine learning to predict the likelihood of various diseases based on user-provided symptoms. This project aims to assist healthcare professionals and individuals in early detection and management of diseases, enhancing preventive healthcare measures.

## Features

- **Disease Prediction**: Predicts the likelihood of multiple diseases based on input symptoms.
- **User-Friendly Interface**: Provides an intuitive web interface for easy interaction.
- **Real-Time Results**: Delivers immediate predictions upon symptom input.

## Technologies Used

- **Python**: Programming language used for backend development.
- **Flask**: Web framework for building the application.
- **Scikit-learn**: Machine learning library for implementing prediction models.
- **HTML/CSS**: For frontend development and styling.
